# 파츠 편집 방법

파츠 그림은 전부 이 폴더의 SVG 파일입니다.

- **`start.bat`으로 생성기를 열면** SVG를 저장할 때마다 자동으로 빌드되고 화면도 알아서 새로 고쳐집니다. 화면의 "빌드" 버튼으로 직접 돌릴 수도 있습니다.
- `index.html`을 더블클릭해서 열었을 때는 `build.bat`을 실행한 뒤 화면을 새로 고칩니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `front` `ahoge` `side` `back` | 앞머리, 바보털, 옆머리, 뒷머리 |
| `face` `skinfx` `makeup` | 얼굴형, 피부특징, 화장 |
| `eye` `pupil` `hl` `brow` `mouth` | 눈 모양, 눈동자 무늬, 하이라이트, 눈썹, 입 |
| `lash` `fold` `lowline` `lowlash` `aegyo` | 속눈썹, 쌍꺼풀, 아래 아이라인, 아래 속눈썹, 애교살. 그림 없이 `_parts.json` 수치만 있고, 눈 파일의 아이라인을 따라 자동으로 그려집니다 |
| `iris` | 눈동자 크기·위치. 그림 없이 `_parts.json`의 수치만 있습니다 |
| `acc` `glasses` | 헤어 악세사리, 안경 |
| `ear` `earring` `facewear` | 귀 모양(고양이귀는 `hairMid-half`), 귀걸이(귓불 (201, 440) 기준, `skinTop` 레이어), 마스크·반창고(`glasses` 레이어, 반창고는 `skinTop-full`) |
| `base` | 항상 그려지는 것: 몸(`body`), 귀(`ear`), 코(`nose`), 기본머리(`hair`), 가이드 선(`guide`) |

## 파일 하나 = 파츠 하나

- 파일 이름이 파츠의 id입니다 (`front/gap.svg` → `gap`).
- 화면에 보이는 이름, 순서, 랜덤 비중은 같은 폴더의 `_parts.json`에 있습니다.
- **새 파츠 추가**: 비슷한 파일을 복사해 이름을 바꾸고 그립니다. `_parts.json`에 한 줄을 넣으면 이름과 순서를 정할 수 있고, 안 넣어도 맨 뒤에 자동으로 붙습니다.
- **삭제**: SVG 파일을 지우면 다음 빌드 때 목록에서도 빠집니다.
- **이름·순서·랜덤 비중**: `start.bat`으로 연 화면의 "항목 편집"에서 고칩니다. 복제(새 파츠 만들기), 삭제(`parts/_trash`로 옮김), 편집기로 열기도 거기서 됩니다.

## 그룹 이름 규칙

SVG 안에서 그룹(레이어) 이름으로 역할을 구분합니다.

| 그룹 이름 | 뜻 |
|---|---|
| `half` | 왼쪽 절반만 그린 것. 생성기가 좌우 반전해서 양쪽에 그립니다 |
| `full` | 그린 그대로 한 번만 그립니다. 좌우가 다른 파츠는 여기에 그립니다 |
| `hairBack-half`, `hairMid-full` 등 | 다른 레이어에 놓을 조각 (레이어 이름 + `-half` 또는 `-full`) |
| `top-half`, `top-full` | **맨 위** 머리. 옆머리보다 앞에 나와야 하는 앞머리 조각, 사과머리 등. `top_half`도 됩니다. 항목 전체를 올리려면 `_parts.json`에 `"top": true` |
| `back-half`, `back-full` | 앞머리 **뒤**로 보낼 조각 (구레나룻 등). 뒷머리 파일에서는 목·몸 뒤. `back_half`도 됩니다 |
| `white`, `lines` | 눈: 흰자 모양 / 눈꺼풀 선. 눈동자는 `white` 모양으로 잘립니다 |
| `upper`, `lower` | 눈: 윗 아이라인 / 아래 라인(노란 가이드) |
| `fill`, `cap`, `tuck`, `edge` | 기본머리: 칠 / 머리 윤곽선 / 귀 뒤로 들어가는 선 / 헤어라인 선 |

- 이름이 없는 그림은 `full`로 들어갑니다. 그룹 구분 없이 그냥 그려도 됩니다.
- `_ref` 레이어는 참고용 반투명 캐릭터입니다. 빌드에서 빠지니 건드리지 않아도 됩니다. (이름이 `_`로 시작하면 전부 빠집니다)
- 눈 파일 (`eye`):
  - `white`: 흰자 모양. 눈동자가 이 모양으로 잘립니다.
  - `upper`: 윗 아이라인 (검은 선 하나). 속눈썹과 쌍꺼풀이 이 선을 따라 자동으로 생깁니다.
  - `lower`: 아래 라인 (노란 선 하나). 그 자체로는 안 그려지고, 아래 아이라인·아래 속눈썹·애교살을 켜면 이 선을 따라 생깁니다.
  - `lines`: 그 밖에 항상 그릴 선 (졸린 눈의 눈꺼풀 주름 등). 없어도 됩니다.
  - `lash`, `fold`, `lowlash`, `aegyo`: 속눈썹·쌍꺼풀·아래 속눈썹·애교살을 **직접 그리고 싶을 때** 이 이름으로 그룹을 만들어 그립니다. 그 눈에서는 자동으로 만든 것 대신 이 그림을 씁니다. 선택지마다 다르게 하려면 `lash-long`, `fold-inner`처럼 뒤에 선택지 id를 붙입니다.
  - 파란 점선 원 `iris`: 눈동자 중심 (생성 결과에는 안 나옵니다).
  - 선은 바깥 눈꼬리(왼쪽)에서 안쪽으로 그리든 반대로 그리든 상관없습니다.

## 레이어 순서 (아래 → 위)

`hairBack` → `body` → `hairMid` → `hairBase` → `ear` → `face` → `skin` → `makeup` → `skinTop` → `mouth` → `eye` → `hairLine` → `brow` → `glasses` → `hairFront` → `hairSide` → `hairTop` → `acc`

## 헤어를 그릴 때

- 기본머리(`base/hair.svg`)가 항상 깔립니다. 앞머리와 옆머리는 그 위에 얹는 덩어리입니다.
- 덩어리의 칠은 헤어라인 위쪽(머리 안)까지 넉넉히 겹쳐 올리고, 선은 드러나는 가장자리에만 긋습니다. 그래야 기본머리와 이음선 없이 합쳐집니다.
- 내려오는 뒷머리는 바깥선을 머리 윤곽 끝점 (171, 297)에서 시작합니다. `_parts.json`의 `"down": true`는 귀 뒤로 들어가는 선을 지우라는 표시입니다.
- 헤어라인을 바꾸려면 `base/hair.svg`의 `edge`와 `face` 폴더 각 얼굴형의 윗부분을 같이 고쳐야 합니다.
